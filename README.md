# Physics II Interactive Course

Published under Turin Prepnik. See AUTHORS.md for full credits and USAGE_TERMS.md for distribution terms.

This repository contains the student course and builds a website and an offline Android APK from the same site/ directory.

- Website: https://asadbek31415-alt.github.io/physics-ii-course/
- Android APK: see Releases. Android 7 or newer; simulator performance depends on the device.
- The website requires a connection; this release does not yet include offline browser caching. The Android APK bundles the course for offline study.
- Feedback is voluntary and uses the separately hosted collector. No administration credentials or response database are included.

Course changes originate in the author's shared course_files directory, exported by tools/prepare-online.cjs in the authoring project. Generated simulator bundles are rebuilt during export.
