# Physics II Interactive Course

Interactive university-level Physics II material, published under **Turin Prepnik**.

## Study the course

**[Read online](https://asadbek31415-alt.github.io/physics-ii-course/)** on a computer, tablet, or phone. The address stays the same when a new version is published. Internet access is required.

**[Download the offline course for computers (ZIP)](https://github.com/asadbek31415-alt/physics-ii-course/releases/latest/download/Physics-II-Interactive-Course.zip)** for Windows, macOS, or Linux. Extract the ZIP, then open `Physics-II-Interactive-Course/index.html` in a browser. Download a new ZIP when a new version is released. Sending feedback still requires internet access.

**[Download the optional offline Android app (APK)](https://github.com/asadbek31415-alt/physics-ii-course/releases/latest/download/Physics-II-Android.apk)** only if you need to study without internet on an Android phone or tablet. It is not needed to use the website. Android may ask you to allow installation from your browser. To update, download and install the newer APK over the old one.

The course files in this repository are also readable online under [`site/`](site/). The automatic GitHub **Source code** ZIP is *not* the ready-to-use offline course; choose the asset named **Physics-II-Interactive-Course.zip** on the [latest release page](https://github.com/asadbek31415-alt/physics-ii-course/releases/latest).

## Updates

The website shows a small one-time notice when you return after an update. It cannot send automatic notifications while you are away. For optional GitHub notifications, sign in to GitHub and select **Watch → Custom → Releases** on this repository. GitHub controls whether you receive email or app notifications. [See release history](https://github.com/asadbek31415-alt/physics-ii-course/releases).
