## Physics II Interactive Course v0.9.8

This release fixes mathematical text in the offline computer ZIP.

- Formulas in the Lorentz force, Biot-Savart, and divergence/curl lessons now render when the extracted course is opened directly from disk.
- The launcher-first ZIP layout and corrected course credits from v0.9.7 remain in place.
- The website, ZIP, and APK use the same release version.
- Feedback remains voluntary and is submitted only when online.

### Choose a format

- **Read online:** https://asadbek31415-alt.github.io/physics-ii-course/
- **Offline computer ZIP:** Download the attached `Physics-II-Interactive-Course.zip` and extract it. On Windows, open `Physics-II-Course-Offline/01 START PHYSICS II COURSE.vbs`; on macOS or Linux, open `Physics-II-Course-Offline/course_files/index.html` in a desktop browser.
- **Offline Android APK:** Download the attached `Physics-II-Android.apk` and install it on an Android phone or tablet. The website is easier when you have internet.

The website requires internet access. Downloaded ZIPs and APKs do not update themselves. Mobile browsers may not open extracted local files reliably; use the website or APK on phones and tablets. The separately hosted feedback collector is the only part of the course that needs an external service for submissions.
